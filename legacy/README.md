# legacy/ ── 構造化する前の原本

`時代戦線.html` は、HTML 1 枚に CSS・マスタデータ・全ロジックが入っていた
構造化前のバージョンです。**動かす対象ではありません。**

置いてある理由は 3 つです。

1. 挙動の突き合わせ ── 「前はこう動いていた」を確かめる原典
2. 数値の出どころ ── バランスの経緯を追う
3. 参照実装 ── 手続き描画の元の形

## 現行版との対応

| 原本の場所 | いまどこにあるか |
|---|---|
| `<style>`（21〜406行） | `src/styles/*.css` |
| `<body>`（409〜607行） | `index.html` |
| `<script id="master-data">` | `src/data/master.json` |
| `<script>`（611〜4735行） | `src/**/*.ts` |

## 一点だけ違うところ

マスタデータの JSON ブロックは、書き出し直したため原本と
バイト単位では一致しません（内容は同一です）。
それ以外の CSS・HTML・JavaScript は原本のままです。

## ブラウザで開くには

`icon-*.png` と `manifest.json` を同じ場所に置いてあります。
ローカルサーバ経由で開いてください（`file://` では Service Worker と
外部マスタ差し替えが動きません）。

```bash
pnpm dlx serve legacy
```
