## 1. これは何か

**原始から現代までの六つの時代を駆け上がる、横スクロール1レーン型のタワーディフェンス**です。
左に自城、右に敵城。中央の1本の戦線に兵を出し合い、**先に相手の城のHPをゼロにしたほうが勝ち**という、いわゆる「城押し合い（ラインディフェンス）」型のゲームです。

最大の特徴は **「進化（時代を進める）」がリスクを伴う一大決断になっている**点で、ゲーム内ヘルプも「いつ進化するかがこのゲームの全て」と明言しています。

### 技術的な構成

| 項目             | 内容                                                                                                                                                                                                                |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 実装             | TypeScript + Vite + Tauri。itch.io の有料ダウンロード（PC 専用）。網につながずに完全に動く                                                                                                                          |
| 描画             | Canvas 2DでPNGを合成。通常兵70フォーム・時代の主6体・召喚妖6体・背景6枚・拠点6種・前景6種・技12種・飛び道具7種・戦闘エフェクト6種・天災6種は遅延読込PNG。HPバー・文字は可変Canvas描画。読込失敗時は手続き描画へ復帰 |
| 音               | Web Audio APIによる手続き生成。全画面で和楽器のBGMが流れ、戦闘では時代ごとに音階・BPM・楽器が変わる（民謡/律/都節/メジャー/ペンタトニック）                                                                         |

## 2. 画面の見かた（HUD）

```
┌──────────────────────────────────────────────────────┐
│ [自城HP]      原始 〜6世紀 採集      [敵城HP][敵の時代] │
│               文 ▓▓▓▓░░ 32/52  残り 18:40   ♪ x1 II 設定│
│                  ［ 進化 → 古代 ］                      │
│                                                        │
│   自城 ◀━━━━━━━ 戦 線 ━━━━━━━▶ 敵城                  │
│                                                        │
│ 石高 ▓▓▓▓▓▓▓░░░ 84 / 110      遺産 +6%                 │
│ [兵カード1][2][3][4][5][6]  [技1][技2]                  │
└──────────────────────────────────────────────────────┘
```

- **自城HP / 敵城HP** … 上部左右のバー。敵側には現在の「敵の時代」も表示される。
- **文（ふみ）** … 進化に必要なゲージ。満ちると「進化」ボタンが金色に光る。
- **残り時間** … 制限時間。20秒を切ると赤く点滅。
- **石高（こくだか）** … 兵を出すための資源。時間で自動回復し、上限がある。
- **遺産** … 置いてきた時代の蓄積による味方全体の底上げ（%表示）。
- **ゴーストマーカー** … 自己ベスト記録があると敵HPバーに白い線が走り、「ベストより先行 12%」のように差分が出る。

## 3. 操作方法

| 操作                            | 内容                                                         |
| ------------------------------- | ------------------------------------------------------------ |
| **兵カードをタップ**            | 石高を消費して兵を1体出撃。兵は自動で前進し、自動で戦う      |
| **カードを横にドラッグ**        | 出撃順（カードの並び）を入れ替える。**戦闘中でも変更可**     |
| **「進化」ボタン**              | 文が満ちているときに押すと次の時代へ（後述）                 |
| **技カード（右端2枚）をタップ** | 時代技（天災 / 妖）を発動                                    |
| **キーボード `1`〜`6`**         | その番号の兵カードを出撃（編成枠の数まで）                   |
| **キーボード `Space`**          | 進化                                                         |
| **キーボード `Q` / `W`**        | 技スロット1 / 2 を発動                                       |
| **`x1` ボタン**                 | 速度切替（x1 → x2 → x4 → x8 のループ）                       |
| **`II` ボタン**                 | 一時停止 / 再開                                              |
| **`♪` ボタン**                  | ミュート切替                                                 |
| **`設定` ボタン**               | 制限時間・進化硬直・表示・音の設定（開くと自動的に一時停止） |

> 時間表記について：内部シミュレーションの30秒が画面上の「1分」に相当します（標準速度 x1 は内部時計の半分の速さで進む設計）。表示上の秒数はすべて換算済みです。

## 4. ゲームの中核ループ ── 石高・文・進化

### 石高（生産資源）

- 時間経過で自動回復。**上限あり**（時代が上がるほど上限も回復速度も跳ね上がる）。
- 開始時は上限の35%を所持。

| 時代 | 石高上限 | 回復/秒 |
| ---- | -------- | ------- |
| 原始 | 110      | 9.3     |
| 古代 | 190      | 16.1    |
| 中世 | 328      | 27.7    |
| 近世 | 566      | 47.9    |
| 近代 | 977      | 82.5    |
| 現代 | 1687     | 142.6   |

### 文（進化ゲージ）

- **時間経過**で貯まる（毎秒 0.759 ×（1 + 時代 × 0.22））
- **敵を倒す**とさらに貯まる（1体あたり 1.6 ×（1 + 敵の時代 × 0.45））
- 必要量：原始 52 → 古代 68 → 中世 83 → 近世 99 → 近代 114（現代は最終時代のため進化なし）

### 進化 ── このゲームの心臓部

「進化」を押すと次の時代へ移行しますが、**移行中は「硬直（無防備）」時間が発生**します。

- **硬直中は兵を1体も出せない**
- **石高が即座にゼロになる**
- 敵はその間も普通に攻めてくる

硬直の長さは設定で **6秒 / 12秒 / 20秒**（表示値）から選べます（既定12秒）。
硬直明けには石高が上限の30%まで戻り、その時代の**文明効果が恒久的に加算**されます。

| 時代                      | 概念 | 進化時に得る文明効果（累積）  |
| ------------------------- | ---- | ----------------------------- |
| 原始 GENSHI（〜6世紀）    | 採集 | ─                             |
| 古代 KODAI（6C〜1185）    | 律令 | 石高上限 +15%                 |
| 中世 CHUSEI（1185〜1600） | 武士 | 騎馬の脚 +12%                 |
| 近世 KINSEI（1600〜1868） | 町人 | 生産費 −8% / **拠点に対空砲** |
| 近代 KINDAI（1868〜1945） | 工業 | 体力 +12%                     |
| 現代 GENDAI（1945〜）     | 情報 | 射程 +8%                      |

さらに、進化するたび／敵を倒すたびに「**時代の遺産**」が貯まり、10ポイントごとに味方全体が **+1.5%**（最大 +36%）強化されます。

### 勝敗条件

- **勝利** … 敵城HPを0にする
- **敗北** … 自城HPを0にされる、または **制限時間切れ**（＝決着がつかなければ負け）

つまり「守りきる」だけでは勝てず、**制限時間内に押し切る**必要があります。

## 5. 兵科と相性

兵科は6種類：**歩兵 / 弓 / 騎馬 / 術 / 機巧 / 飛行**

### 三すくみ（有利 ×1.9 / 不利 ×0.45）

```
歩兵 ──▶ 弓 ──▶ 騎馬 ──▶ 歩兵
```

### 特殊相性（有利 ×1.8 / 逆方向は ×0.45）

- 騎馬 ▶ 術、騎馬 ▶ 機巧
- 術 ▶ 歩兵、機巧 ▶ 歩兵
- **弓 ▶ 飛行**

### 重要なルール

- **飛行に攻撃が届くのは「弓」だけ**（＋近世以降の拠点対空砲、＋台風などの一部の技）
- **機巧は拠点へのダメージ ×3.0**（＝城を割る専門職）／飛行は ×1.15
- 拠点への攻撃には共通倍率 ×2.6 がかかる
- 通常攻撃が命中すると相手を拠点側へ少しノックバックさせる。遠距離は押す力が弱く、阻む者と一時耐性中の味方は動かない
- 飛行は**同時出撃数に上限**（通常3機、ステージにより5機）

## 7. 時代技 ── 「天災」と「妖」

技は2系統あり、**時代ごとに2つ**を持ち込みます。進化すると自動的にその時代用の技に切り替わるので、戦闘中のボタンは常に2つのままです。

| 時代 | 技       | CT  | 効果                                          |
| ---- | -------- | --- | --------------------------------------------- |
| 原始 | 蟲の群れ | 26  | 6秒間、戦場じゅうの敵を削り続ける             |
| 古代 | 雷雲     | 30  | 6秒間、敵の密集地点に雷が落ちる               |
| 中世 | 地震     | 34  | 8秒間、**敵の足が半分・受ける被害が2倍**      |

## 8. 敵側の仕組み

敵も**時間経過で勝手に時代を進めます**。進化を遅らせすぎると純粋なステータス差で押し切られます。

- **時代進行**：ステージごとの `foeSchedule`（例：s01 は 0/137/291/454/635/832秒）で自動的に時代が上がる
- **通常の湧き**：時間とともに湧き間隔が短くなり、同時存在数の上限も時代とともに増える
- **大物**：一定間隔で「造る者」系の強化個体（HP ×2.5・攻撃 ×1.25・サイズ ×1.45）が出現
- **敵の守備隊**：敵城HPが **70% / 45% / 25%** を切るたびに、まとまった数の守備兵が湧く（一本槍の押し切りを止める仕掛け）
- **時代の主（ボス）**：敵城HPが一定割合を切ると出現する固有ボス
- **終盤の窓**：敵が最終時代に到達したあと、予備兵力（同時上限）が22秒ごとに減っていく＝**押し切るチャンスが開く**

### 時代の主（各時代の固有ボス）

| 時代 | 主         | 固有能力                                           |
| ---- | ---------- | -------------------------------------------------- |
| 原始 | 大猪       | **突進**（予兆のあと高速突撃し、味方を吹き飛ばす） |
| 古代 | 怨霊       | **呪い**（範囲の味方の攻撃を6割に、8秒）           |
| 中世 | 鬼武者     | **薙ぎ払い**（範囲攻撃）                           |
| 近世 | 黒船       | **艦砲射撃**（5秒ごとに自城を直接砲撃）            |
| 近代 | 装甲列車   | **装甲**（機巧と弓以外からの被害が半減）           |
| 現代 | 無人機母艦 | **艦載機**（8秒ごとに飛行ユニットを2機射出）       |

主を討伐すると勾玉 +15%・素材 1.6倍のボーナスがつきます。

## 9. 拠点（メタ進行）

タイトル画面の「はじめる」を押すと拠点（ホーム）に入ります。

### 通貨・資源

| 資源     | 入手                       | 用途                    |
| -------- | -------------------------- | ----------------------- |
| **勾玉** | ステージ報酬               | 召集（ガチャ）          |
| **暦**   | 8分に1回復（最大5）        | 使うとその戦の報酬が2倍 |
| **素材** | ステージ報酬・ガチャの重複 | 強化（レベルアップ）    |

### メニュー

- **出陣** … ステージ選択。章ごとに区切られ、前ステージをクリアすると次が開く
- **編成** … 所持している系譜から最大6つを選び、出撃順を決める（ドラッグで並べ替え）
- **強化** … 素材で系譜のレベルを上げる（Lv最大10、1レベルにつき体力・攻撃 +9%）。技系統も強化可（Lv最大5、効果 +8% / CT −4%）
- **召集** … 勾玉で系譜を引く（1回 30 / 10回 270）。未所持なら解放、所持済みなら素材 +8
- **技** … 時代ごとに持ち込む2つを選び直す
- **遊びかた / 設定**

### 初期所持系譜

歩む者・投げる者・群れる者・祈る者・阻む者 の5系譜。残り11系譜は召集で解放します。

## 10. ステージ構成 ── 全25戦・5章

| 章                   | ステージ                                                                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| **一章　野を拓く**   | 1 序戦 / 2 石の川 / 3 獣道 / 4 稲の邑 / 5 土器の丘（関門・主が二度）                                                                             |
| **二章　都を巡る**   | 6 律の道 / 7 高床の倉（機巧隊） / 8 祝いの杜（弓衆） / 9 早馬の報（騎馬隊） / 10 都の門（関門・主が二度）                                        |
| **三章　城を攻める** | 11 山の砦（盾陣） / 12 矢来の陣（弓衆） / 13 谷の伏兵（群れ・速攻） / 14 鉄砲の坂（騎馬隊） / 15 天守の下（関門・剣士隊・主が二度）              |
| **四章　海と鉄**     | 16 湊の朝 / 17 浮田の空（空襲） / 18 蔵前の火（群れ・進化硬直20秒） / 19 煉瓦の壁（要塞戦・堅城） / 20 黒煙の湾（関門・空襲・主が二度）          |
| **五章　無音の戦線** | 21 鉄路の音（装甲列車） / 22 灯火管制（夜戦・騎馬・速攻） / 23 電波の海（弓衆） / 24 無人の空（空襲・同時5機） / 25 終戦線（最終決戦・主が三度） |

ステージごとに**敵の主力兵科が違う**ため、編成を組み替えて挑むのが基本です。

- 敵の傾向：`mix`（混成）/ `swarm`（群れ）/ `arrow`（弓衆）/ `horse`（騎馬隊）/ `iron`（機巧隊）/ `wall`（盾陣）/ `blade`（剣士隊）/ `sky`（空襲）
- **速攻ステージ**（13・22）は制限時間が設定値の72%
- **s18 蔵前の火** は進化硬直が強制的に20秒
- **s19 煉瓦の壁** は敵城HPが突出して高い（94,500）
- **s24 無人の空** は飛行の同時上限が5機に増える

## 11. 設定でいじれること

| 項目                 | 内容                                                                               |
| -------------------- | ---------------------------------------------------------------------------------- |
| **制限時間**         | 3〜60分を1分刻み、または無制限。次の戦から反映                                     |
| **進化の硬直時間**   | 6秒 / 12秒 / 20秒。短いほど進化のリスクが減る                                      |
| **兵科マーク**       | 頭上の記号（歩兵＝四角、弓＝三角、騎馬＝菱形、術＝四芒星、機巧＝六角、飛行＝山形） |
| **FPS表示**          | フレームレート・ユニット数・解像度・詳細度の表示                                   |
| **音**               | BGM / 効果音の個別ON/OFF、音量3段階                                                |
| **最初からやり直す** | 現在のステージを再スタート                                                         |

## 12. ゴースト（自己ベスト）

勝った戦のうち最速のものは、**シード＋入力ログ**として保存されます。
次に同じステージへ挑むと、その記録が裏で再シミュレートされ、敵HPバー上の白いマーカーとして「自己ベストのペース」が並走します。「ベストより先行 12%」のように差分が表示されるので、タイムアタックの指標になります。

## 13. 勝つための要点（設計から読み取れるセオリー）

1. **進化のタイミングが全て。** 硬直中は無防備なので、「敵の波を捌き切った直後」「壁役が前線で耐えている間」に押すのが基本。
2. **文は敵を倒すほど早く貯まる。** 撃破が進化を早め、進化が撃破力を上げる正のループを作る。
3. **飛行対策の弓を必ず1枠。** 弓（と近世以降の拠点対空砲）以外は飛行に一切当たらない。
4. **城を割るのは機巧。** 拠点ダメージ ×3.0。攻めきる局面では機巧が必須。
5. **三すくみを崩す札を持つ。** 「断つ者」は不利を無視して全兵科に通るが石高が重い。「兵を射る者」は対歩兵 ×4.2 だが騎馬に無力、と極端な札が多い。
6. **敵城HP 70/45/25% で守備隊が湧く。** ここを見越して技（天災）を温存しておく。
7. **敵が最終時代に達したあとは敵の予備兵力が減っていく。** 耐えきれば押し切る窓が開く。
8. **制限時間切れは敗北。** 守り一辺倒は成立しない。
9. **暦は強いステージ・初回突破に使う。** 報酬2倍かつ初回ボーナスと重複する。

## 14. 修正済みの不整合

読み込み時に見つかった実装とUIのズレは、以下のとおり修正済みです。

### 1. 「遊びかた」の文面が古かった → マスタから自動生成に変更

タイトル／ヘルプ画面に「縄文から令和まで、**八つの時代**」「**五すくみ**。有利なら1.6倍、不利なら0.7倍」と、実データ（六時代・三すくみ・1.9倍/0.45倍）と食い違う文言が焼き込まれていました。

数値を文章に焼き込む限り必ずまた古くなるため、**副題と本文をマスタデータから組み立てる `renderHelp()` を追加**しました。時代数・相性の輪・倍率・対空砲の登場時代・キー割り当ては、すべて `ERAS` / `AFF` / `META` から導出されます。`data/master.json` で差し替えたときも自動で追従します。

HUDと戦績画面に残っていた `縄文` / `令和` / `JOMON` のプレースホルダも `—` に置き換えました（いずれも起動時に上書きされる箇所ですが、ソース上の古い時代名を残さないため）。

### 2. キーボードで最後の枠と2つ目の技が押せなかった → 枠数に追従

`1`〜`5` 決め打ちだったため、編成枠が6のときに6枠目がキーから出せませんでした。**実際のカード数に追従**するよう変更（`1`〜`9` を受け、存在する枠だけ反応）。
同様に技も `Q`（スロット1）だけで2つ目が押せなかったので、**`W` にスロット2を割り当て**ました。

### 3. PWA関連ファイルが存在しなかった → 実体を作成

HTMLは `manifest.json` / `sw.js` / `icon-180.png` / `icon-192.png` を参照していましたが、実体がありませんでした。参照を消すのではなく、**PWAとして成立するよう実体を作成**しています。

| ファイル               | 内容                                                                                                                                                                                                                                |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `manifest.json`        | 全画面・横向き固定、テーマ色 `#0E1116`、アイコン4種（maskable含む）                                                                                                                                                                 |
| `sw.js`                | 殻（HTML・マニフェスト・アイコン）を先読みキャッシュ。**`data/master.json` だけは網優先**（運営が差し替えた値を古いキャッシュで塗り潰さないため）。書体はキャッシュ、それ以外の別オリジンは素通し。オフライン時は遷移要求に殻を返す |
| `icon-180/192/512.png` | 一本の戦線を挟んで向かい合う二つの天守。色はゲーム本体の `--sumi` / `--kin` / `--ai` / `--shu` をそのまま使用                                                                                                                       |

### 検証したこと

- 主要スクリプトの構文チェック（`node --check`）
- 生成される「遊びかた」の文面を、**実マスタ**と**差し替えを想定した別マスタ**（4時代・四すくみ・特殊相性なし・枠3）の両方で確認
- ヘッドレスChromeで実起動し、コンソールエラーなし・文面がデータどおり生成されることを確認
- `sw.js` の install / activate / fetch を Node上の疑似ServiceWorker環境で15項目テスト（先読み・旧世代の掃除・素通し判定・master.jsonの網優先・オフライン時の殻返却）

### 残る仕様上の注意

- **`data/master.json` による差し替えは `http/https` 配信時のみ有効。** `file://` で直接開いた場合は内蔵JSONのみで動作します（`tryExternalMaster()` がプロトコルを見て判断）。
- **Service Worker も `file://` では動きません。** オフライン動作を試すにはローカルサーバ経由で開いてください。
